# NumPy Performance Analytics

## Overview

This project demonstrates practical data analytics using NumPy.

Instead of focusing on ETL or file processing, the project highlights NumPy's strengths in numerical computing, vectorized operations, and large-scale array processing.

Synthetic employee data is generated and analyzed entirely using NumPy without relying on Pandas.

---

# Objectives

- Practice NumPy fundamentals
- Work with large numerical datasets
- Apply vectorized operations
- Perform statistical analysis
- Compare NumPy with traditional Python loops
- Understand why NumPy is the foundation of Pandas

---

# Technologies Used

- Python 3
- NumPy

---

# Dataset

The dataset is generated programmatically.

Each employee record contains:

- Employee ID
- Department
- Salary
- Attendance
- Overtime Hours
- Performance Score

Approximately 100,000 synthetic employee records are generated.

---

# Analytics Performed

- Average Salary
- Median Salary
- Highest Salary
- Lowest Salary
- Standard Deviation
- Department-wise Employee Count
- Department-wise Average Salary
- Department-wise Average Performance
- Top 10 Highest Salaries
- Bottom 10 Salaries
- Employees with Low Attendance
- High Performing Employees
- Bonus Calculation
- Final Salary Calculation

# Performance Comparison

The project compares:

- Traditional Python loops

to demonstrate NumPy's performance advantages for numerical computations.

# Learning Outcome

This project serves as a practical application of NumPy concepts before moving to Pandas for real-world tabular data processing.
